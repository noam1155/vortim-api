# טסטים

סקריפטים לבדיקה עצמית של השרת. כל קובץ בודק שלב אחד.

## איך מריצים
1. הפעל את השרת (python app.py) בטרמינל אחד.
2. בטרמינל שני, מתוך תיקיית tests, הרץ את הטסט של השלב שסיימת, למשל:

    python test_stage1_routes.py

הטסט מדפיס PASS/FAIL לכל בדיקה, וסיכום בסוף.

## הערות חשובות
- הטסטים מניחים את ההגדרות הסטנדרטיות: token נשלח בכותרת
  Authorization: Bearer <token>, וגוף הבקשות ב-JSON עם השדות
  username / password. אם בחרת פורמט אחר — התאם את הטסט.
- הטסטים משתמשים בפרשות bereshit ו-noach, שבהן יש כבר וורטים לדוגמה.
- טסט שלב 5 בודק רק את מה שמוגדר בבירור (וורט ארוך בודד לאורח מול משתמש
  מחובר). ההחלטה על התנהגות הרשימה השלמה לאורח היא שלך — הטסט לא כופה אותה.
- דרוש requests (כבר ב-requirements.txt): pip install -r ../requirements.txt
