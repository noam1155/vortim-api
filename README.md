# Vortim API

שרת Flask שמגיש וורטים לפי פרשת השבוע.

## התקנה והרצה
1. צור סביבה וירטואלית והפעל אותה.
2. התקן את התלויות:  pip install -r requirements.txt
3. הרץ:  python app.py

## מבנה
- app.py       — האפליקציה וה-routes
- helpers.py   — כל פונקציות העזר
- config.py    — הגדרות
- data/        — הנתונים (פרשות, משתמשים, מנהלים)
- docs/        — מסמכי ההנחיות לבנייה, לפי שלבים

בנה את הפרויקט לפי המסמכים בתיקיית docs/, שלב אחר שלב, והעלה ל-GitHub בסוף כל שלב.
